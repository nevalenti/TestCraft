`.env.example` at the repo root covers the full local stack (`just up`).
Copy it to `.env` and fill in real values before starting. In production
these map to `infrastructure/helm/testcraft/values.secrets.yaml` instead —
see [Production Deployment](/docs/guides/production/).

<Aside type="caution">
  Defaults like `changeme` and `minioadmin` are fine for local development only.
  Rotate every one of them before deploying — see [Security
  Hardening](/docs/guides/security/).
</Aside>

## Database

| Variable            | Default                                                       | Notes                                                 |
| ------------------- | ------------------------------------------------------------- | ----------------------------------------------------- |
| `POSTGRES_USER`     | `testcraft`                                                   |                                                       |
| `POSTGRES_PASSWORD` | `changeme`                                                    |                                                       |
| `POSTGRES_DB`       | `testcraft_db`                                                |                                                       |
| `DATABASE_URL`      | `postgresql://testcraft:changeme@localhost:5432/testcraft_db` | Full connection string used by the API                |
| `APPLY_MIGRATIONS`  | `false`                                                       | API applies EF Core migrations on startup when `true` |

## Messaging

| Variable       | Default                                             |
| -------------- | --------------------------------------------------- |
| `RABBITMQ_URL` | `amqp://testcraft:changeme-rabbitmq@localhost:5672` |

## Caching (Redis)

| Variable    | Default | Notes                                                                                                           |
| ----------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `REDIS_URL` | —       | Optional — unset falls back to a no-op cache. Production requires a password: `redis://:<password>@redis:6379`. |

<Aside type="note">
  The local Compose stack runs a Redis container, but `.env.example` leaves
  `REDIS_URL` unset — local dev uses the no-op cache unless you set it
  explicitly.
</Aside>

## Observability & misc

| Variable                                              | Default                                        | Notes                                                        |
| ----------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| `SEQ_URL` / `LOKI_URL` / `SEQ_API_KEY` (also Gateway) | —                                              | Structured log sinks — leave empty to disable                |
| `GRAFANA_ADMIN_PASSWORD`                              | `changeme`                                     | Production only; local Grafana allows anonymous admin access |
| `CORS_ALLOWED_ORIGINS`                                | `https://yourdomain.com,http://localhost:3000` | Comma-separated origins allowed to call the API              |
| `METRICS_TOKEN`                                       | —                                              | Bearer token required on `/api/metrics` when set             |
| `SWAGGER_BASIC_AUTH_USERNAME` / `PASSWORD`            | —                                              | Gate `/api/docs` in production                               |
| `HANGFIRE_BASIC_AUTH_USERNAME` / `PASSWORD`           | —                                              | Gate the Hangfire background-job dashboard                   |
| `SEQ_BASIC_AUTH_USERNAME` / `PASSWORD` (Gateway)      | —                                              | Gate `/seq` at the gateway, in front of Seq's own login      |

## What is TestCraft?

TestCraft manages test cases, test plans, and test runs, and imports JUnit / Allure
results straight from CI — GitHub Actions, GitLab CI, and Jenkins.

<CardGrid>
  <Card title="Test management" icon="list-format">
    Projects → suites → test cases, with drag-and-drop test plans.
  </Card>
  <Card title="CI-native" icon="rocket">
    JUnit / Allure import and live run logs from any CI system.
  </Card>
  <Card title="Self-hosted" icon="seti:docker">
    Runs anywhere via Docker Compose or the bundled Helm chart.
  </Card>
  <Card title="Open architecture" icon="puzzle">
    .NET 10 API + React 19 SPA, documented in the Reference section.
  </Card>
</CardGrid>

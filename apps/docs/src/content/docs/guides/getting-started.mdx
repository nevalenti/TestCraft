Set up a local development environment in a few minutes.

## Prerequisites

- **Docker**
- **.NET 10 SDK**
- **Node.js 24**
- **pnpm**
- **just**
- **jq**
- **yq**

## Setup

<Steps>

1. Clone the repository and install dependencies:

   ```bash
   git clone https://github.com/nevalenti/TestCraft.git
   cd TestCraft
   pnpm install
   cp .env.example .env
   cp apps/web/.env.example apps/web/.env
   ```

2. Set `APPLY_MIGRATIONS=true` in `.env`.

   <Aside type="caution">
     Skip this and the database schema stays empty — the API will fail on its
     first request.
   </Aside>

3. Start the local infrastructure via Docker Compose:

   ```bash
   just up
   ```

4. Run the API and the web app outside Docker:

   ```bash
   # API
   dotnet run --project apps/Api/src/TestCraft.Api
   ```

   ```bash
   # Web
   pnpm --filter testcraft-web dev
   ```

</Steps>

| Service    | URL                                                              |
| ---------- | ---------------------------------------------------------------- |
| Web        | [http://localhost:3000](http://localhost:3000)                   |
| API        | [http://localhost:5000](http://localhost:5000)                   |

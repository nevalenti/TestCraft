Run the API and the web app on your machine against containers for everything else.

## Prerequisites

- **[Docker](https://www.docker.com/get-started/)** with Compose
- **[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)**
- **[Node.js 24](https://nodejs.org/en/download)** and **[pnpm](https://pnpm.io/installation)**
- **[just](https://github.com/casey/just)**
- **[uv](https://docs.astral.sh/uv/getting-started/installation/)**: `just hooks-install` and `just workflow-audit` run their tools through `uvx`
- **[jq](https://jqlang.org/download/)** and **[yq](https://github.com/mikefarah/yq)**: `just up` uses them to render local config

## Setup

<Steps>

1. Clone the repository and install the JavaScript dependencies:

   ```bash
   git clone https://github.com/nevalenti/TestCraft.git
   cd TestCraft
   pnpm install
   ```

2. Start the containers (Postgres, Redis, RabbitMQ, MinIO, Keycloak, Mailpit, GlitchTip and the observability stack):

   ```bash
   just up
   ```

   The first run creates `.env`, `apps/web/.env` and `e2e/.env` from their `.env.example`. Later runs add any keys the examples gained since.

3. Run the API and the web app, both in one terminal:

   ```bash
   just dev
   ```

   The API applies migrations and seeds sample data before it starts, then restarts when its code changes. To run them separately, use `just api-serve` and `just web-dev`.

4. Open [http://localhost:3000](http://localhost:3000) and sign in as `e2e@testcraft.pro` with the password `e2e-test-password`.

   <Aside>
     You can also register a new account. Keycloak asks you to verify the email
     address; the message lands in Mailpit.
   </Aside>

</Steps>

## Everyday commands

```bash
just down               # stop the containers, keep their data
just nuke               # stop the containers and delete every volume (asks first)
just api-db-reset       # drop and recreate the dev database, then migrate
just api-migration AddX # add an EF Core migration
just codegen            # regenerate @testcraft/types and the web SDK after changing apps/Api/openapi/contract/v1.json

just api-test-unit      # .NET unit and architecture tests, no Docker needed
just api-test           # every .NET test project, including integration tests
pnpm --filter testcraft-web test

just lint
just format
```

To run the Helm chart the way production does, see [Local cluster](/docs/guides/hosting/#local-cluster).

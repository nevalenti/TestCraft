Set up a local development environment in a few minutes.

## Prerequisites

- **[Docker](https://www.docker.com/get-started/)**
- **[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)**
- **[Node.js 24](https://nodejs.org/en/download)**
- **[pnpm](https://pnpm.io/installation)**
- **[uv](https://docs.astral.sh/uv/getting-started/installation/)** (`just dev` runs honcho through `uvx`)
- **[just](https://github.com/casey/just)**
- **[jq](https://jqlang.org/download/)**
- **[yq](https://github.com/mikefarah/yq)**

## Setup

<Steps>

1. Clone the repository and install dependencies:

   ```bash
   git clone https://github.com/nevalenti/TestCraft.git
   cd TestCraft
   pnpm install
   cp .env.example .env
   cp apps/web/.env.example apps/web/.env
   ```

2. Start the local infrastructure via Docker Compose:

   ```bash
   just up
   ```

3. Create the database schema:

   ```bash
   just api-migrate
   ```

   <Aside type="caution">
     Skip this and the database schema stays empty — the API will fail on its
     first request.
   </Aside>

4. Run the API and the web app outside Docker, both in one terminal:

   ```bash
   just dev
   ```

   The API runs in the Development environment, restarts when code changes, and applies migrations and seeds sample data before it starts. To run them separately instead, use `just api-serve` and `pnpm --filter testcraft-web dev`.

</Steps>
